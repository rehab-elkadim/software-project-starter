# Worked example: Task Tracker

A fictional, deliberately small project that shows the starter's documents filled in at the intended level of detail. Read it to see what "specific and brief" looks like; do not copy its decisions into your project.

**Scenario:** a solo developer builds a web app where a small team's members track their own tasks. The first release covers sign-in, creating, editing, and completing tasks.
